# 출시 전 운영 확인

이 문서는 법률 자문이나 법적 적합성 인증이 아닙니다. 실제 운영 주체와 서비스 제공 지역의 정보가 확인되어야 하므로 아래 항목을 운영자가 관련 전문가와 검토해야 합니다.

- [ ] 운영 주체의 법적 상호·사업자 정보, 연락처, 서비스 제공 지역을 확인합니다.
- [ ] 실제 호스팅 업체의 접속 기록·보관 기간과 앱의 개인정보 안내가 일치하는지 확인합니다.
- [ ] 대상 국가의 개인정보·소비자보호 규칙을 검토하고, 실제 서비스 운영 방식에 맞는 안내를 마련합니다.
- [ ] 결제처의 판매자 지위, 실제 가격과 환불 정책을 앱·결제 화면의 표시와 대조합니다.
- [ ] 유료 판매 전에 제품별 라이선스 검증과 상품 ID를 설정하고 다른 상품의 키가 통과하지 않는지 실제 결제 환경에서 검증합니다.
- [ ] 패턴 기반 탐지는 누락 가능성이 있습니다. 민감한 정보를 공유하기 전에 결과를 확인하도록 안내합니다.
- [ ] 상품명, 도메인, 타사 상표 사용과 비제휴 안내를 출시 지역에서 확인합니다.
